# Release Scope

This release focuses on creating a reproducible, tagged repository that demonstrates a canonical path for the Tenacious Ventures screening brief. Key components include:

1. Ruby 3.3.12 and Rails 7.1 baseline
2. Reproducible setup and CI pipeline
3. Capability and claims truth layer
4. Normalized Wave 1 governance
5. Complete DIT reference implementation
6. Portable artifact generation
7. Rust-backed independent verification

## Included
- DIT synthetic operational evidence
- Signed-event intake
- Evidence projection
- Gap detection
- Append-only human review
- Australian profile determination
- Portable reliance artifact
- Independent Rust verification

## Excluded
- Generalized production marketplace
- Live payments
- Every country adapter
- Production carbon-credit issuance
- Full identity-provider integration

## Hard Non-Goals
- No legacy path renaming before release
- No Wave 2 features included
- No external identity integration

This release establishes the foundation for future proof-of-concept work.
