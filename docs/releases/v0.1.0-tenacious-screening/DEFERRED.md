# Deferred Features

Features that are intentionally deferred until after the v0.1.0-tenacious-screening release:

- Generalized production marketplace
- Live payments
- All country adapters beyond Australia and New Zealand
- Production carbon-credit issuance
- Full identity-provider integration
- Broad soil, robotics, fermentation, or hydrogen expansion
- Renaming of athian_ink_rails_bootstrap directory

These features are out of scope for the initial screening release to maintain focus on the core proof.
