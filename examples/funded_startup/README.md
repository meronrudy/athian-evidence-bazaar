# Funded Startup Example

Northstar Methane Systems is a synthetic demonstration company.

This example supplies fixture source material for the AgEvidence scaffold:

- trial report;
- invoice;
- ration log;
- measurement export;
- expected evidence candidates;
- expected material gaps;
- normalized fixture response.

The fixture represents candidate evidence extraction only. It is not protocol approval, VVB determination, emissions certification, or legal reliance.

Seeded Rails data maps these source records to stable global evidence identifiers such as `evidence.animal_cohort`, `evidence.intervention_delivery`, `evidence.feed_record`, `evidence.weight_record`, and `evidence.baseline_ration`. The same source graph is evaluated against Canada and Australia starter adapter packs to demonstrate country-neutral evidence reuse.
