# Sea Forest Bioactive Product Lot Manifest Proof Kit

Maps a synthetic Asparagopsis batch CSV row into an `InterventionEvent` using
the reusable `BioactiveProductLot` domain profile.

```bash
agevidence proof run sea_forest.bioactive_product_lot_manifest --format table
agevidence proof run sea_forest.bioactive_product_lot_manifest --rust-validate
```

This proof validates local structure and provenance only. It does not establish
regulatory eligibility, scientific validity, carbon-credit issuance,
third-party verification, claim ownership, or institutional reliance.
