# DIT AgTech Water Dosing Intervention Proof Kit

Maps a synthetic uHUB-style water dosing webhook into an `InterventionEvent`
using the reusable `WaterDosingIntervention` domain profile.

```bash
agevidence proof run dit.water_dosing_intervention --format table
agevidence proof run dit.water_dosing_intervention --rust-validate
```

This proof validates local structure and provenance only. It does not establish
regulatory eligibility, scientific validity, carbon-credit issuance,
third-party verification, claim ownership, or institutional reliance.
