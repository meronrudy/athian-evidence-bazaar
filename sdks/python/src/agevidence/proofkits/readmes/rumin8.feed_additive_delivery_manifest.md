# Rumin8 Feed Additive Delivery Manifest Proof Kit

Maps a synthetic feed-mill delivery receipt into an `InterventionEvent` using
the reusable `FeedAdditiveDelivery` domain profile.

```bash
agevidence proof run rumin8.feed_additive_delivery_manifest --format table
agevidence proof run rumin8.feed_additive_delivery_manifest --rust-validate
```

This proof validates local structure and provenance only. It does not establish
regulatory eligibility, scientific validity, carbon-credit issuance,
third-party verification, claim ownership, or institutional reliance.
