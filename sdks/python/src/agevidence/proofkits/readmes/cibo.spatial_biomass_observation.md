# Cibo Labs Spatial Biomass Observation Proof Kit

Maps a synthetic spatial API response into two `SpatialObservation` primitives:
pasture biomass FOO and fractional cover. The reusable domain profile is
`SpatialBiomassObservation`.

```bash
agevidence proof run cibo.spatial_biomass_observation --format table
agevidence proof run cibo.spatial_biomass_observation --rust-validate
```

This proof validates local structure and provenance only. It does not establish
regulatory eligibility, scientific validity, carbon-credit issuance,
third-party verification, claim ownership, or institutional reliance.
