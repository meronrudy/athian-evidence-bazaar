# MEQ Objective Carcass Measurement Proof Kit

Maps a synthetic hyperspectral carcass measurement record into an `Observation`
using the reusable `ObjectiveCarcassMeasurement` domain profile.

```bash
agevidence proof run meq.objective_carcass_measurement --format table
agevidence proof run meq.objective_carcass_measurement --rust-validate
```

This proof validates local structure and provenance only. It does not establish
regulatory eligibility, scientific validity, carbon-credit issuance,
third-party verification, claim ownership, or institutional reliance.
