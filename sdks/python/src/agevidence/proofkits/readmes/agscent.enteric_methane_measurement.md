# Agscent Enteric Methane Measurement Proof Kit

Maps a synthetic breath sensor VOC/UART record into an `Observation` using the
reusable `EntericMethaneMeasurement` domain profile.

```bash
agevidence proof run agscent.enteric_methane_measurement --format table
agevidence proof run agscent.enteric_methane_measurement --rust-validate
```

This proof validates local structure and provenance only. It does not establish
regulatory eligibility, scientific validity, carbon-credit issuance,
third-party verification, claim ownership, or institutional reliance.
