# Agronomeye Spatial Digital Twin Manifest Proof Kit

Maps a synthetic LiDAR/multispectral digital twin manifest into a `SourceRecord`
using the reusable `SpatialDigitalTwinManifest` domain profile.

```bash
agevidence proof run agronomeye.spatial_digital_twin_manifest --format table
agevidence proof run agronomeye.spatial_digital_twin_manifest --rust-validate
```

This proof validates local structure and provenance only. It does not establish
regulatory eligibility, scientific validity, carbon-credit issuance,
third-party verification, claim ownership, or institutional reliance.
