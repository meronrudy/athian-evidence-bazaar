# SwarmFarm Precision Chemical Application Proof Kit

Maps a synthetic SwarmConnect spray telemetry webhook into an `OperationalEvent`
using the reusable `PrecisionChemicalApplication` domain profile.

```bash
agevidence proof run swarmfarm.precision_chemical_application --format table
agevidence proof run swarmfarm.precision_chemical_application --rust-validate
```

This proof validates local structure and provenance only. It does not establish
regulatory eligibility, scientific validity, carbon-credit issuance,
third-party verification, claim ownership, or institutional reliance.
