# Record a Model Run

Use `ModelRun` for a derived result generated by a model, algorithm, or
simulation.

```python
from agevidence.primitives import ModelRun
from agevidence.provenance import check

run = ModelRun(
    model_id="example-model",
    model_version="2.3.1",
    implementation_digest="sha256:model-implementation",
    input_commitments=["sha256:evidence-bundle"],
    parameters={"seed": 42},
    execution_environment={"runtime": "python-3.12"},
    started_at="2026-08-12T18:00:00Z",
    completed_at="2026-08-12T18:00:05Z",
    outputs=[{"observable": "estimated_reduction", "value": 12.4, "unit": "kg_ch4"}],
    limitations=["synthetic example"],
    verification={
        "adapter_id": "example-adapter-v1",
        "adapter_digest": "sha256:adapter",
        "normalized_output_digest": "sha256:output",
    },
)

report = check(run)
print(report.structural_validity)
print(report.provenance_completeness)
```

The source evidence remains unchanged. Each model execution creates its own
provenance-bearing result.

Local model-run validation does not establish scientific validity, regulatory
eligibility, carbon-credit issuance, third-party verification, claim ownership,
or institutional reliance.
