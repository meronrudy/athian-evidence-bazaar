# Optional Hosted Services

The open SDK can be used independently.

For organizations that need managed infrastructure, Agevidence can provide
hosted capabilities for:

- organization identity;
- private evidence graphs;
- high-volume ingestion;
- program/profile management;
- review workflows;
- managed verification;
- retention and audit;
- institutional APIs.

Hosted services sit above the local evidence layer. They should not be required
for a developer to build primitives, run fixture demos, test source adapters, or
inspect local provenance.
