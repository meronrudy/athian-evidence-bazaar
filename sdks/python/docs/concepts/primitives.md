# Primitives

Agevidence exposes stable evidence primitives that remain useful across
different downstream applications.

## SourceRecord

Original source material before transformation.

```python
from agevidence.primitives import SourceRecord

source = SourceRecord(
    source_system="farm_management_platform",
    record_id="feed-2026-00421",
    observed_at="2026-08-12T09:10:00Z",
)
```

## Observation

A measurement or physical assertion about a subject.

```python
from agevidence.primitives import Observation

observation = Observation(
    subject="animal:982000001234",
    observable="liveweight",
    value=481.4,
    unit="kg",
    observed_at="2026-08-12T14:05:11Z",
)
```

This object says what was observed. It does not say whether the observation
satisfies a carbon methodology, financing requirement, assurance standard, or
regulatory program.

## SpatialObservation

An observation attached to geometry or a spatial boundary.

```python
from agevidence.primitives import SpatialObservation

observation = SpatialObservation(
    subject="paddock:P-17",
    geometry={"type": "Point", "coordinates": [151.2, -33.8]},
    observable="feed_on_offer",
    value=1810,
    unit="kg_dm_ha",
    observed_at="2026-08-12T00:00:00Z",
)
```

## InterventionEvent

Something physically applied or changed.

```python
from agevidence.primitives import InterventionEvent

event = InterventionEvent(
    target="herd:H31",
    intervention="feed_additive",
    quantity=2.1,
    unit="kg",
    batch="LOT-9281",
    occurred_at="2026-08-12T16:00:00Z",
)
```

## OperationalEvent

A machine, system, or equipment action.

```python
from agevidence.primitives import OperationalEvent

event = OperationalEvent(
    machine="robot:RB-8",
    operation="spot_spray",
    started_at="2026-08-12T17:00:00Z",
    completed_at="2026-08-12T17:18:00Z",
)
```

## ModelRun

A derived result generated by a model, algorithm, or simulation.

```python
from agevidence.primitives import ModelRun

run = ModelRun(
    model_id="example-model",
    model_version="2.3.1",
    implementation_digest="sha256:model-implementation",
    input_commitments=["sha256:evidence-input"],
    parameters={"seed": 42},
    execution_environment={"runtime": "python-3.12"},
    started_at="2026-08-12T18:00:00Z",
    completed_at="2026-08-12T18:00:05Z",
    outputs=[{"observable": "estimated_reduction", "value": 12.4, "unit": "kg_ch4"}],
    limitations=["synthetic example"],
    verification={"normalized_output_digest": "sha256:output"},
)
```

The source evidence stays unchanged. Each model execution creates its own
provenance-bearing result.
