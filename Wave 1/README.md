# Wave 1 Design-Advisor Workspace

## Program Charter
Wave 1 is a public design-partner program for agricultural technology companies whose operational systems already create commercially valuable evidence events. AgEvidence translates selected operational records into portable evidence contracts and independently verifiable reliance artifacts without replacing participating companies' products, data platforms, or customer relationships.

## Participation Paths
| Level | Company Commitment | AgEvidence Commitment | Output |
|---|---|---|---|
| Design Reviewer | 30–45 min review | Correct public workspace | Validated workflow map |
| Design Advisor | 2–3 structured reviews | Build evidence contract | Reviewable contract and artifact |
| Design Partner | Named use case | Implement integration | Pilot-ready evidence bundle |

## Company Workspace Structure
Each company folder contains:
- Public-information hypothesis
- Evidence flow thread
- Evidence gap register
- Proposed event contract
- Reliance artifact specification
- Design-review questionnaire

## Participation Process
1. Review the workspace and correct the proposed evidence flow
2. Identify commercially sensitive fields
3. Define the minimum portable artifact
4. Graduate to formal partnership
