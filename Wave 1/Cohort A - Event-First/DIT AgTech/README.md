# DIT AgTech - Product Documentation

## Company Overview
DIT AgTech (trading as DIT AgTech) is ranked highest in priority with a score of 41. They provide proportional liquid supplement dosing hardware (uDOSE), cloud telemetry dashboards (uHUB), and advisory software (Neville AI) for extensive pastoral livestock operations.

## Product Portfolio
- **uDOSE**: Proportional liquid supplement dosing hardware
- **uHUB**: Cloud telemetry dashboards
- **Neville AI**: Advisory software

## Business Model
- Three-year partnership model supplying hardware with zero upfront technology cost
- Monetizes through supplement supply
- Remote proportional dosing units installed at station water points

## Technical Architecture
- Remote proportional dosing units meter fluid consumption
- Inject supplement ratios into drinking water
- Creates direct telemetry trail

## Target Customers
- Pastoral cattle enterprises
- Project developers
- Corporate beef buyers
- Verra auditors (under DIT's public-comment Verra VM0041 grouped project)

## Evidence Lifecycle
1. **Manufacturing & Dispatch**: Supplement batch COA, formulation density, dispatch docket
2. **Installation & Calibration**: Device serial, water-point GPS, flow meter calibration record
3. **Daily Intervention**: Volumetric water flow, injection ratio, fluid depletion log
4. **Quantification & Review**: VM0041 model execution, baseline comparison, abatement
5. **Assurance & Reliance**: VVB audit determination, credit issuance, Scope 3 assignment

## Key Integration Points
- Hardware telemetry integration
- Water point monitoring systems
- Livestock management platforms
- Carbon credit verification systems
